A one-line error message from a kitchen toaster to its owner, written by a small program (Node 22, stdlib only, deterministic, offline). Run it with `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts` and it writes the line to `/tmp/out/entry.txt`.
